Authentication Methods Implemented
Basic Authentication

Uses username and password encoded in Base64 to authenticate users.

Simple Token Authentication

A token is generated after login and must be included in API requests for authorization.

~ JWT Authentication

Uses JSON Web Tokens to securely transmit authentication information between client and server.
